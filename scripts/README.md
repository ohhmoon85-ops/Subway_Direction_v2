# 방향 알리미+ 전국 지하철 노선 데이터

국가철도공단 도시광역철도 **역사정보**·**노선정보**(데이터 기준 2026-06-30)로 만든 이용자용 노선 데이터입니다.
노선 36개, 역 939개(환승역은 1개)이며, 철도·KTX는 제외했습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `stations.json` | 역 목록: 이름(한·영·한자), 위도·경도, 권역, 지나는 노선 |
| `lines.json` | 노선 목록: 색, 권역, 구간별 역 순서 |
| `report.md` | 생성 결과와 확인할 점 |
| `build_lines.py` | 원본 엑셀 → JSON 변환 스크립트 (데이터 갱신 때 다시 실행) |

## stations.json

```json
{ "id": "수도권:시청", "name_ko": "시청", "name_en": "City Hall", "name_hanja": "市廳",
  "lat": 37.5657, "lng": 126.9769, "region": "수도권",
  "lines": ["SEOUL-1", "SEOUL-2"], "operators": ["서울교통공사"] }
```

- `id`는 `권역:역명`입니다. 같은 권역에 같은 이름의 다른 역이 있으면 `@노선번호`가 붙고 `display_ko`에 화면용 이름이 들어갑니다. 예: `양평(5호선)` / `양평(경의중앙선)`, `신촌` 2곳, `좌천` 2곳.
- 같은 이름이라도 권역이 다르면 다른 역입니다(서울 `시청` ≠ 부산 `시청` ≠ 대전 `시청`).

## lines.json

```json
{ "id": "SEOUL-2", "name_ko": "2호선", "color": "#00A84D", "region": "수도권",
  "segments": [ { "name": "순환선", "kind": "loop", "stations": ["수도권:시청", "…"] } ] }
```

구간(`segments`)의 `kind`는 세 가지입니다.

| kind | 뜻 | 예 |
| --- | --- | --- |
| `line` | 양방향 일반 구간 | 대부분 |
| `loop` | 순환 — 마지막 역 다음이 첫 역, 양방향 | 2호선 본선 |
| `oneway_loop` | 한 방향 순환 — 마지막 역 다음이 첫 역, 반대 방향 없음 | 6호선 응암순환 |

갈래가 있는 노선은 구간을 여러 개로 나눴습니다(1호선 경인선·광명·서동탄, 2호선 성수·신정지선, 5호선 마천 방면, 경의중앙선 서울역 방면, 경춘선 광운대).
두 구간이 만나는 역(예: 구로, 강동, 가좌)은 같은 `id`를 쓰므로, 모든 구간을 이어 그래프를 만들면 갈아타기 없이 갈래를 넘나드는 경로가 나옵니다.

## 안내 계산에 쓰는 법

1. 모든 노선의 모든 구간에서 이웃한 두 역을 잇는 간선을 만듭니다(`oneway_loop`는 한 방향, 순환은 끝↔처음도 연결).
2. 간선마다 노선 `id`를 붙이고, 노선이 바뀌는 곳에 환승 벌점을 주어 최단 경로를 찾습니다.
3. 첫 구간에서 내릴 역까지의 간선 수가 **몇 번째 역**, 진행 방향 끝 역(또는 갈래의 끝 역)이 **방면**, 바로 다음 역이 **다음 역**입니다.

## 확인할 점

- **GTX-A**는 원본 데이터에 없어 넣지 못했습니다.
- **인천공항 자기부상철도**는 운행 여부를 확인해야 합니다.
- **급행·직통**(9호선, 경의중앙선, 수인분당선, 공항철도 등)은 운행정보 파일로 2단계에 반영합니다.
- 원본 노선정보가 옛 역명을 쓰는 곳은 현재 역명으로 바꿨습니다: 신길온천→능길, 성서공단→성서산업단지, 성당못→서부정류장.
- 원본 역 좌표 오류 1건(양원역)을 바로잡았습니다.
- 원본 노선정보가 순서를 잘못 적었거나 빠뜨린 곳을 바로잡았습니다.
  - 분당선: 왕십리·청량리 추가, 이매 위치 수정
  - 안산·과천선: 금정 추가
  - 경의중앙선: 용산~회기 구간 추가
  - 수인분당선: 사리~달월 사이를 4호선 공용구간(한대앞~오이도)으로 연결
  - 6호선: 응암순환 수정
- 역 순서는 운행정보의 실제 열차 정차 순서와 대조했습니다(1,053개 역 간 연결 중 이름 표기가 같은 곳은 모두 일치).
